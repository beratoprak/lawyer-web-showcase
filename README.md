# Law Firm Website + Admin Panel (Showcase)

This repository is a **showcase** of a law firm website and its admin panel experience.
The real project is kept private due to client confidentiality.

## Highlights
- Next.js based marketing website (hero, practice areas, value props, contact flow)
- “Ask a Lawyer” form UX with validation-ready structure
- Admin panel architecture (content-first approach)

## Tech Stack
- Next.js (App Router)
- TypeScript
- UI: modern card-based layout, strong CTA hierarchy
- Focus: performance, UX, clean information architecture
