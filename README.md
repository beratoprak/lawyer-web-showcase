# Law Firm Website + Admin Panel (Showcase)

This repository is a **public showcase** of a law firm website experience and its related admin panel approach.  
The full production project is kept **private** due to client confidentiality and security considerations.

## What This Showcase Demonstrates
- A modern, trust-focused landing experience for a law firm
- Clear information architecture (Practice Areas → content → conversion)
- “Ask a Lawyer” contact flow designed for a clean and frictionless UX
- Admin panel mindset: content-first structure and scalable management

## Highlights
- Premium / luxury UI language (gold accents, serif typography, strong CTA hierarchy)
- Practice areas grid and structured content pages
- Conversion-driven sections (“Why Choose Us”, CTA blocks)
- Contact form layout ready for validation & backend integration

## Tech Stack
- Next.js (App Router)
- TypeScript
- UI: Tailwind-based layout + custom gradients / card system
- Focus: performance, UX, clean information architecture

## Demo Code (Safe)
The repository includes **sanitized demo components** inspired by the real project.
Private business logic, client data, and production dependencies were removed.

- `demo/HukukAlaniCards.tsx` — “Practice Area” page hero + 3-card navigation system (Dilekçeler / Emsal Kararlar / Makaleler) in the same luxury UI style.
